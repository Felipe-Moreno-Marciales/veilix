# Veilix

Extension de privacidad para WhatsApp Web, desarrollada de forma independiente.

## Estado

Proyecto en preparacion (fase 1). Aun no hay funcionalidades implementadas.

## Alcance acordado

- Difuminar nombres de contactos.
- Difuminar fotografias de contactos.
- Difuminar vistas previas de mensajes.
- Difuminar mensajes de conversaciones.
- Difuminar el campo de escritura.
- Investigar la viabilidad de ocultar el indicador de escritura.
- Recuperacion local limitada de mensajes previamente almacenados, con consentimiento.
- Facilitar la configuracion oficial de privacidad para ver estados.
- Facilitar la configuracion oficial de privacidad para ocultar la presencia en linea.

## Desarrollo

Se usara TypeScript, React y WXT para una extension compatible con Chrome, Edge y Firefox. El desarrollo comenzara en la rama `development` usando GitHub Codespaces y Codex.

> Veilix no esta afiliado a WhatsApp ni a Meta.
